
# Markerless Hand Motion Capture System

A multi-camera markerless motion capture system designed to record hand movements and reconstruct three-dimensional hand kinematics using deep learning-based pose estimation.

The system combines synchronized camera acquisition, automated hand tracking, and 3D reconstruction to enable quantitative analysis of hand movements without physical markers.


## Overview

The workflow consists of four main stages:

1. **Camera setup and synchronization:** Multiple cameras are synchronized using an Arduino-based external triggering system.
2. **Video acquisition:** Synchronized videos are recorded using SpinView and the Jarvis Acquisition Tool.
3. **2D pose estimation:** Hand keypoints are automatically tracked in each camera view using SLEAP.
4. **3D reconstruction:** The resulting 2D keypoints are combined using SLEAP-Anipose to reconstruct three-dimensional hand movements.

## Requirements

### Hardware
- Multiple compatible cameras
- Computer with USB connections
- Arduino board
- Breadboard and connecting wires
- ChArUco calibration board
- GPU-enabled computer (recommended for SLEAP)

### Software
- [SpinView](https://www.teledynevisionsolutions.com/products/spinnaker-sdk/)
- [Arduino IDE](https://www.arduino.cc/en/software)
- Jarvis Acquisition Tool
- [SLEAP](https://sleap.ai/)
- [SLEAP-Anipose](https://github.com/talmolab/sleap-anipose)

## 1. Camera Setup

Before starting acquisition:

1. Position the cameras around the recording area.
2. Connect the required cameras to the computer using USB ports.
3. Verify the electrical connections between the cameras, breadboard, and Arduino.
4. Open SpinView and confirm that all connected cameras are detected.

### Camera configuration

Configure the following parameters in SpinView:

- **Exposure time:** Approximately 10 ms
- **Trigger mode:** Enabled
- **Trigger source:** Line 3
- **Trigger activation:** Rising edge

Keep the camera configuration windows open during acquisition.

## 2. Camera Synchronization

The cameras are synchronized using an external trigger generated by an Arduino board.

The Arduino code controls the recording frequency, with a default acquisition rate of **50 Hz**.

### Procedure

1. Open Arduino IDE.
2. Upload the camera synchronization code to the Arduino board.
3. Open the Serial Monitor.
4. Press `b` to start camera triggering.
5. Press `s` to stop camera triggering.
6. Confirm that the cameras respond correctly in SpinView.

Adjust camera focus if necessary.

## 3. Video Acquisition

Open the Jarvis Acquisition Tool.

1. Navigate to the camera configuration section.
2. Select **Auto Detect Cameras**.
3. Confirm that all cameras are correctly identified.
4. Verify that the exposure and trigger settings match the SpinView configuration.
5. Select the directory where recordings will be saved.

### Recording procedure

1. Ensure Arduino triggering is stopped.
2. Click the red recording button in the acquisition software.
3. Start Arduino triggering.
4. Perform the experimental task.
5. Stop Arduino triggering.
6. Stop the recording in the acquisition software.

### Synchronization verification

After acquisition, inspect the generated `metadata.csv` file.

Verify that all cameras recorded the same number of frames to check synchronization.

## 4. Camera Calibration

Record calibration videos using a **ChArUco calibration board**.

Calibration should be repeated whenever the position of any camera changes.

These recordings are used to determine the camera parameters required for accurate 3D reconstruction.

## 5. 2D Hand Pose Estimation

[SLEAP](https://sleap.ai/) is used to automatically identify and track hand keypoints in the recorded videos.

For each camera, the output consists of two-dimensional hand keypoint trajectories.

A computer with a suitable GPU is recommended for this stage.

## 6. 3D Reconstruction

[SLEAP-Anipose](https://github.com/talmolab/sleap-anipose) is used to combine the 2D keypoint trajectories from multiple camera views.

Using the camera calibration parameters, the pipeline reconstructs the three-dimensional positions of the tracked hand keypoints.

This enables markerless analysis of hand movements in 3D space.
